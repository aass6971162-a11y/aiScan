# 清页扫描

完全离线的 Android 文档检测与校正应用。当前实现包含：

- CameraX 实时预览、RGBA 分析、同一 ViewPort 坐标映射和最新帧背压策略。
- 内置 DocAligner LCNet100 四角热图与 UVDoc 二维展平权重，ONNX Runtime CPU 离线推理。
- 实时和拍照均执行四角模型复核，OpenCV 提供质量诊断和图像处理；加载失败明确显示回退状态。
- 原图透视/连续边缘位移/AI 网格合成重采样、低频光照校正、彩色/灰度/黑白输出。
- 四角和四个边缘控制点、拖动放大镜、处理结果预览。
- “裁剪”仅控制图片编辑页：开启时显示可调整边框，点击“完成”才应用裁剪；关闭时保存完整画面，仍可手动旋转和使用滤镜。
- 连拍完成、相册导入和进入文档列表均保留原图，不在后台自动裁剪；列表缩略图完整适配画面。
- 关闭裁剪时拍照先呈现全幅原图，开启裁剪时再执行高精度边框检测；拍照保存与实时分析使用独立线程。
- 无滤镜/旋转/裁剪的“完成”走原始 JPEG 直存，不重新解码压缩；连拍批量一次写入索引，列表缩略图按需生成。
- 指定分辨率时先读取尺寸再按需降采样，避免整张超大照片解码；完成后清理相机临时 JPEG，保留仓库原图。
- search-v5：原图/ROI 严格四角共识，按需扩边；优先保留先获得整体支持的内部前景页，避免更大的纸堆外框替换它。不将不同层的角拼接成新框。
- 实时仅缓存已验证的两个尺度参数，每次从当前帧重新推理；冲突后重搜。分析启动间隔 300ms，实际推理可能更久。两帧确认配合运动自适应平滑，漏检旧框降低可信度并在 1.2 秒后清除。
- 低置信、贴边或仅靠背景扩边找回的拍照候选需调整或点击“确认当前边框”。
- 拖动角点时相邻边缘中点同步移动，边框曲线经过控制点。扩边只提供检测背景，不恢复照片外内容。
- 完成页面原子持久化、重新校正、排序、删除和多页 PDF 分享。
- 关闭系统云备份并排除设备迁移，扫描照片留在当前设备；分享仅由用户主动发起。

## 构建与测试

```shell
./gradlew :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
ANDROID_SERIAL=emulator-5554 ./gradlew :app:connectedDebugAndroidTest
```

版本为 1.5（versionCode 6），`minSdk` 为 33。实际模型运行时为 ONNX Runtime Android
`1.23.2`，OpenCV 为 `4.12.0`。工程仍保留旧 LiteRT `1.4.2` 适配器和依赖，
当前内置模型不走 LiteRT。构建保留四个 ABI；本次未做 APK 瘦身。

## 模型与回归

模型契约位于 `app/src/main/assets/models/manifest.json`，包括来源、版本、SHA-256、
输入输出及后处理定义。启动校验哈希并执行一次模型推理；失败能力不会伪装为已就绪。
展平默认关闭，启用时验证网格范围与折叠；失败后可关闭展平重新处理。

回归包含 24 项 JVM 与 41 项 Android 仪器测试：模型数值对齐、坐标映射、几何和
网格校正、远近/轻微出画/局部边缘中断、空背景拒绝、裁剪页确认、20 张公开 UVDoc
固定图片，以及一张真实叠纸图和 9 个曝光/距离/旋转/取景变体。当前帧复检和场景切换
单独验证。另覆盖裁剪开关两种状态下的导入/连拍原图一致性、缩略图四角可见、裁剪缓存失效、EXIF 与手动旋转，以及 40 MP 图片编辑保存。
新增性能回归检查关闭裁剪时快速进入编辑、开启裁剪时补做检测、双页连拍的完整索引和页面顺序。
受控变体与已经调参使用的公开图片都不能替代独立盲测。

本次没有重新训练权重；基础去阴影仍为传统处理，没有训练光照网络。计划中的
`IoU >= 0.97`、自动可用率 `>= 98%`、GPU/NPU 和三类旗舰设备性能指标仍需独立盲测。

已核验的公开权重、数据集、许可证和 LiteRT 风险见
[`docs/model-data-selection.md`](docs/model-data-selection.md)，机器可读的固定版本与哈希见
[`training/public_resources.json`](training/public_resources.json)。已分发模型的许可证随 APK
保留。后续迁移 LiteRT 或硬件委托时，须重新通过转换数值、算子兼容与真机性能检查。

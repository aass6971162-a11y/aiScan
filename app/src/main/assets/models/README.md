# 已内置的离线模型

`manifest.json` 包含真实文件、来源、SHA-256、输入归一化及输出定义。
APK 同时包含 ONNX Runtime Android 1.23.2，首次启动无需联网或 Google Play。

- DocAligner 1.1.1 LCNet100：彩色 BGR/255、NCHW 256×256，输出四角热图。
  用于拍照进入裁剪页时的检测；不提供分割掩码。
  search-v5 按需验证原图、局部区域和 8%、15%、25%、40%、60%、75% 扩边；必要时补 10%/12% 邻近尺度。
  优先保留已验证的前景页面，不再全局偏向更大纸堆；确认后提前返回。小目标先做严格四角局部复检。
  各角单独获得支持但四角整体不一致时保留一个完整候选并要求确认，不混合不同纸层的四角。
  结果始终映射回原图；拍照候选贴边或仅靠扩边找回时需用户确认，不生成照片外内容。
  实时取景分析启动间隔为 300 ms；稳定时每帧仅复检找到的两种尺度，不缓存角点。冲突时重新搜索。
  实际更新周期仍受推理耗时限制；两帧确认、移动时提高跟随速度，大幅跳变不直接混合。
  CameraX 1.6.2 输入按 R/G/B/A 字节读取。短时漏检只保留不可靠提示框，1.2 秒后移除。
- UVDoc 026782d：安全读取官方权重并导出 2D head，RGB/255、NCHW 712×488，
  输出原生 45×31 反向网格。开启 AI 褶皱展平后运行。

启动在后台分别验证哈希、创建 CPU 会话并执行一次推理；单项失败不会阻止其他能力。
展平异常会阻止生成该结果，用户可关闭展平后重新处理。低置信度边框需要手动确认。
传统去阴影明确标为“基础去阴影”；实时 AI 辅助不是分割模型，复杂候选仍需拍照后确认。

DocAligner 和 UVDoc 的许可证随目录附带。导出脚本与数值报告见 `training/`；
Android 数值回归资源见 `app/src/androidTest/assets/model-golden/`。
目前只验证 CPU，不宣称 GPU/NPU 或 LiteRT 已适配，也不宣称通过复杂场景精度验收。

Float arrays: little-endian float32, NCHW, CPU ONNX Runtime 1.23.2.
Corner input is a lossless 256x256 PNG to avoid platform JPEG decoder differences.
UVDoc input is a lossless 488x712 PNG; tensor input is RGB/255.
See training/numerical_report.json for graph provenance and export parity.

distance-small/near/clipped.png are controlled compositions of the same reference card
onto its table background (800x600), not independent real-world benchmark images.
Known target corners in pixel order TL/TR/BR/BL:
small: (320,240), (480,235), (485,335), (315,340)
near: (12,20), (785,9), (788,580), (8,590)
clipped: (-8,20), (785,9), (788,580), (-5,590)
Clipped results must require confirmation and may only export visible source pixels.

distance-edge-gap.png is the original 512x512 reference with a 20px-wide, background-
colored stroke interrupting 30% of its left edge (the four corners remain visible).
The regression checks that the four predicted corners stay within 0.015 normalized
distance of the unmodified reference. It is a controlled occlusion, not a real-world
occlusion accuracy benchmark.

complex-stacked-pages.jpg is the user-supplied real failure image (1920x2560, SHA-256
c72bb452df7ea4a570f4f2517afc3357b73a99cfebd47c56df21bac12a0bd1f0). It contains a
low-contrast white page over other white pages and a dark device. The OpenCV fast path
must reproduce no usable quad; the padded color model must recover the foreground page.
Approximate normalized TL/TR/BR/BL corners are (.064,.132), (.815,.166), (.920,.838),
(.205,.944). This single user image is a regression fixture, not a benchmark dataset.
